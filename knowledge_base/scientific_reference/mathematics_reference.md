# Mathematics Reference

Tier 1 anchor source used by every deductive tab.

## Algebra

Whatever is done to one side of an equation must be done to the other.
To rearrange a formula, apply inverse operations in reverse order.

    Quadratic formula: for a x² + b x + c = 0,  x = (−b ± √(b² − 4ac)) / 2a

## Proportion

If y = k x, y is directly proportional to x. Doubling x doubles y.
If y = k / x, y is inversely proportional to x. Doubling x halves y.

## Geometry

    Pythagoras: a² + b² = c² for a right-angled triangle with hypotenuse c.
    Circle: circumference = 2 π r, area = π r². π ≈ 3.14159.
    Sphere: surface area = 4 π r², volume = (4/3) π r³.
    Cylinder: volume = π r² h.
    Triangle area = ½ × base × height.
    Angles in a triangle sum to 180°.

A 3-4-5 triangle (or any multiple, such as 6-8-10) has a right angle opposite the
longest side. Builders use this to set out square corners with a tape or knotted rope.

## Trigonometry

For a right-angled triangle with angle θ:

    sin θ = opposite / hypotenuse
    cos θ = adjacent / hypotenuse
    tan θ = opposite / adjacent

    Sine rule: a / sin A = b / sin B = c / sin C
    Cosine rule: c² = a² + b² − 2ab cos C

Degrees to radians: multiply by π / 180.

## Logarithms and Exponentials

    log10(100) = 2. ln is the natural log, base e ≈ 2.71828.
    Exponential decay: N = N0 e^(−t/τ). After one time constant τ, about 37% remains.
    Half-life t½ = τ × ln 2 ≈ 0.693 τ.

## Rates

    Rate of change = change in quantity / change in time.
    Average speed = total distance / total time.

## Units and Dimensional Checks

Every term added or equated must have the same units. Checking units is a quick test
for an error in a derivation.

    SI base units: metre (m), kilogram (kg), second (s), ampere (A), kelvin (K),
    mole (mol), candela (cd).
